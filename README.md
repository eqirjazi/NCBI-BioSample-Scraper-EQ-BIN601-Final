# NCBI BioSample Scraper
EQ BIN601 Final Project

---
## Purpose:
This is a Python script that aimed to scrape American Gut Project survey responses from NCBI BioSample records. The goal was to eventually have a tool for scraping these responses for further analysis such as saving civ files with specific information and creating plots from them. 

---
## Description:

Reads one text file containing NCBI BioSample accession numbers, removes duplicates, creates four smaller example input files, and scrapes NCBI BioSample webpages.

For this project, I chose to use 200 randomly selected IDs scraped from the result file. The script reads one text file containing BioSample IDs and randomly selects 200 IDs by default. It also divides the original list into four smaller example input files. In the code you can change the sample size with --sample-size, or use 0 to scrape every ID. The script saves the complete scraped data, then creates separate CSV files and plots for four survey categories (these were the ones I chose as examples): sex, vitamin D supplement frequency, weight in kg and weight change.

---
## Example Inputs:

The example_inputs folder contains the original biosample_result file, which includes the full list of NCBI BioSample accession numbers collected from the American Gut Project. The four additional files biosample input 1-4  were created by splitting the original list into four equal groups. These smaller files provide sample inputs that can be used to test the Python scraper without having to process the entire list at once.

---   
## Output Results:

The output results folder contains the results generated by the Python scraper. It includes the complete scraped BioSample survey data, filtered CSV files for selected survey questions (sex, vitamin D supplement frequency, weight change and weight in kg), and a plots subfolder containing visualizations of survey responses. The CSV files include the BioSample IDs and their corresponding survey questions and answers.

---
## Some helpful code for terminal to run the entire project

    To test with 10 randomly selected BioSamples in terminal:
        python ncbi_survey_scraper_EQ_CODE.py biosample_result.txt --sample-size 10

    To Scrape 200 random BioSamples and create the four plots (default) in terminal:
        python ncbi_survey_scraper_EQ_CODE.py biosample_result.txt --plot

    To Scrape every BioSample and create the four plots in terminal: 
        python ncbi_survey_scraper_EQ_CODE.py biosample_result.txt --sample-size 0 --plot
